# Capture Format



Every proof artifact should answer these questions.



## Objective

What am I proving?



## Environment

What systems, devices, networks, or tools were involved?



## Starting State

What was true before I made changes?



## Work Performed

What did I actually do?



## Evidence

What machine-generated evidence proves it?



## Validation

How did I confirm the result?



## Troubleshooting

What failed, what did I check, and what fixed it?



## What I Learned

What do I understand now that I did not understand before?

- Run 1:

- Run 2:

- Run 3:



## Final Status

QUEUED / ACTIVE / THIN / PROVEN
